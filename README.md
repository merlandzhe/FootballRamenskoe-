# Субботний футбол — сайт записи

Проект: Vite + Supabase. Поддерживает общий список участников, отметку «Я оплатил», ручную проверку оплаты организатором и админ-панель.

## Что работает в проекте
- Единый список участников из базы данных.
- Запись на ближайшую субботу (время 20:00–22:00, взнос 350 ₽).
- Участник может сообщить об оплате.
- Организатор входит через Supabase Auth и вручную подтверждает поступление денег.
- Настраиваемые ссылки на оплату СБП и группу WhatsApp.
- Live-обновления списка при изменениях в базе.

## 1. Создай базу данных
1. Открой https://supabase.com/ и создай проект.
2. В меню SQL Editor выбери New query.
3. Скопируй весь файл `supabase/schema.sql`, вставь его и нажми Run.
4. Открой Project Settings → API (или Connect/API Keys). Скопируй Project URL и publishable/anon key. Никогда не вставляй `service_role` key в клиентский код.

## 2. Подключи проект к сайту
Открой `src/config.js` и замени:
- `SUPABASE_URL` на Project URL;
- `SUPABASE_ANON_KEY` на publishable/anon key;
- `WHATSAPP_URL` на ссылку-приглашение в вашу группу;
- `PAYMENT_URL` на официальную ссылку СБП/платёжную страницу ОЗОН Банка **или** `PAYMENT_QR_IMAGE_URL` на публичный URL изображения вашего QR-кода.

Не нужно придумывать номер телефона или ссылку на оплату. Используй QR/ссылку, которую выдал банк. Если есть только QR-картинка на телефоне, загрузите её в публичное хранилище/на сайт и укажи прямой URL изображения. Не публикуй банковские секреты.

## 3. Создай вход организатора
1. В Supabase открой Authentication → Users → Add user и создай пользователя с email и надёжным паролем.
2. Скопируй SQL ниже в SQL Editor, заменив email на свой:
   ```sql
   insert into public.admins (user_id)
   select id from auth.users where email = 'ТВОЙ_EMAIL';
   ```
3. Нажми Run. Только пользователь, чей UUID находится в таблице `admins`, получит права организатора.

## 4. Запусти сайт локально
Установи Node.js LTS с https://nodejs.org/ и в терминале из папки проекта выполни:
```bash
npm install
npm run dev
```
Открой URL, который покажет Vite.

Для проверки готовности к публикации:
```bash
npm run build
```
Готовая версия появится в папке `dist`.

## 5. Опубликуй сайт бесплатно
Подойдут Netlify или Vercel:
1. Загрузи папку проекта в GitHub.
2. Создай новый проект на Netlify/Vercel из репозитория.
3. Build command: `npm run build`
4. Publish/output directory: `dist`
5. После публикации открой выданный URL на телефоне и проверь запись и вход организатора.

## Как будет проходить оплата
1. Игрок записывается на игру.
2. Переходит по настроенной ссылке или сканирует QR-код СБП и переводит 350 ₽.
3. Возвращается на сайт и нажимает «Я оплатил» рядом со своим именем.
4. Организатор проверяет поступление в приложении банка и подтверждает оплату в админ-панели.

Статус не подтверждается автоматически по одному нажатию. Для автоматического подтверждения понадобится официальный платёжный сценарий с провайдером/API и серверная часть.

## Важные ограничения MVP
- Сейчас запись создаётся без личного аккаунта; браузер сохраняет ID записи, чтобы показать владельцу кнопки «Я оплатил» и «Отменить запись». Очистка данных браузера может лишить этих кнопок. Для устойчивого контроля доступа можно добавить одноразовый код/ссылку для управления записью.
- Публичные имена и статусы видны всем посетителям страницы.
- Уникальность имён ограничена в рамках одного события; если в компании есть два человека с одинаковыми именами, лучше добавить фамилию или короткий ник.
- Проект не содержит платёжных реквизитов и не обрабатывает деньги сам. Вставляйте только официальную ссылку/QR, полученные от банка.
